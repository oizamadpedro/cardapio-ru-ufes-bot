# cardapio-ru-ufes-bot

## About
A telegram bot still in development to warn you about the Ufes RU lunch and dinner menus.

Bot link: https://t.me/menu_ru_ufes_bot

RU - Ufes menu: https://ru.ufes.br/cardapio

## Usage
/help - check out functionalities

/notify - toggle notifications - when you have it activated, you will always receive the lunch and dinner menu as soon as it's out.
